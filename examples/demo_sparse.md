# 演示论文 A：稀疏检索阅读助手（虚构教学资料）
## Abstract / 研究问题
这是一份虚构的演示文本，用于测试论文阅读 Agent，不是已发表论文。
研究问题：如何在低计算资源下为研究人员提供可溯源的论文问答？
## Method / 核心方法
方法使用按页分块、TF-IDF 稀疏向量与余弦相似度检索。检索结果携带文档编号和页码。生成模型基于原文片段组织答案。
## Dataset and experiment / 实验设置
教学示例假设使用 20 篇合成短文，采用关键词匹配问题。没有真实实验结果，不可引用为科学证据。
## Limitation / 局限性
稀疏检索依赖词面重合，跨语言和同义改写可能召回不足。PDF 扫描件需要 OCR，复杂表格的文字顺序可能失真。
