# 演示论文 B：语义检索阅读助手（虚构教学资料）
## Abstract / 研究问题
这是一份虚构的演示文本，用于与演示论文 A 对比，不是已发表论文。
研究问题：如何提升同义表述问题下的论文证据召回？
## Method / 核心方法
方法使用稠密 embedding 表示段落，再进行向量相似度检索和重排序。生成模型引用检索得到的原文，用户偏好单独存储。
## Dataset and experiment / 实验设置
教学示例假设使用 40 篇合成短文，采用同义改写问题。没有真实实验数值。由于与 A 的资料规模和问题类型不同，不能直接判断效果高低。
## Limitation / 局限性
稠密模型需要额外下载或调用服务；语义相似不保证事实一致。方法仍需核验引用，重排序增加响应时间。
