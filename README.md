# Paper Atlas · 论文阅读与对比 Agent

全 Python 实现的本地研究工作台。界面由 Streamlit 生成，核心包括 RAG、长期记忆和大模型 Function Calling。

## 启动

本机已具有依赖，可直接双击 `start.bat`，浏览器访问 http://127.0.0.1:8501 。关闭启动窗口即停止服务。
新机器先安装 Python 3.10+，双击 `install.bat` 建立独立虚拟环境并安装依赖，再双击 `start.bat`。
也可在项目目录运行：

```powershell
python -m streamlit run app.py --server.address 127.0.0.1 --server.port 8501
```

## 使用

侧栏分为「总览」「研究助手」「论文库」「研究记录」「设置」。默认进入「总览」首页；研究助手内可切换问答、精读和对比。手动证据检索在论文库内，阅读计划和记忆中心在研究记录内。

1. 默认进入「总览」。首次使用请到「论文库」上传本地文字型 PDF、TXT、Markdown；虚构演示资料入口已移除。
2. 在「阅读问答」选择论文，输入关键词或问题。默认本地证据模式不需要 Key，返回可核验的原文片段，不模拟大模型回答。也可以先在「论文库」选中论文，点击「就这篇提问」或「只检索这篇」直接带着该论文跳转。回答与原文证据中的页码链接会直接进入论文库对应页的原文预览，不再打开独立页面。论文库详情可按自动识别的章节跳页，在「提取文字 / 原始页图」间切换；保存笔记会自动标注当前页码。
3. 在「设置」切换到大模型 Agent 模式，填写兼容 Chat Completions 的 Base URL、模型 ID、Key，应用设置并测试连接。服务必须支持 Function Calling。
4. 在「论文对比」选择 2–6 篇论文和对比维度，生成或导出 Markdown 报告。
5. 在「记忆中心」保存阅读偏好、研究方向和笔记。之后提问会读取记忆。模型生成的内容仅在用户点击保存后进入长期笔记。
6. 在「阅读计划」按待读 / 精读中 / 已读查看全部论文，可在卡片上切换状态、带论文去提问或进入编辑；研究待办支持添加、完成和删除。

每个阅读对话会保存论文范围。切换论文后，模型只参考同一论文范围的历史，代词式追问会结合该范围内最近的提问来检索。精读和对比结果自动归档，可以从各自页面的历史记录找回。每份结果和 Markdown 导出都会标明论文、任务、关注点和生成时间。

本地 Ollama 接口示例为 `http://localhost:11434/v1`。需要先安装并运行一个支持工具调用的模型；本项目不自动下载大模型。云端请填写服务商给出的兼容地址与模型名称。

模型设置默认填入 PokeAPI 的 `https://www.poke2api.com/v1` 和模型 `gpt-6.1-terra`。填写 Base URL 和 Key 后，可以点击「查询可用模型」，应用会向 Base URL 追加 `/models` 并列出模型 ID。

选择运行模式后立即生效，并保存到此浏览器。大模型 Agent 模式下点击「应用设置」可保存 Base URL、模型 ID 和 API Key。回到本地证据模式仍会保留已保存的连接信息。同一浏览器访问同一应用地址时会自动恢复。可以用「清除此浏览器的模型配置」清除保存值并恢复启动默认值。

可用 `PAPER_AGENT_BASE_URL`、`PAPER_AGENT_MODEL` 和 `PAPER_AGENT_API_KEY` 预设连接信息。设置 `PAPER_AGENT_MODE=agent` 可以把大模型 Agent 模式设为启动默认值。恢复浏览器配置后，服务端在当前会话内存中使用 Key 发起模型请求。

## 技术实现

- `app.py`：九个中文页面，包括资料预览、聊天、对比、记忆和模型配置。
- `paper_agent/store.py`：PDF 解析、去重、页级分块、阅读状态与 SQLite 持久化。
- `paper_agent/retrieval.py`：BM25 / TF-IDF / RRF / MMR 与进程内索引缓存。
- `paper_agent/workflows.py`：证据检索、精读工作台、阅读计划。
- `paper_agent/calculator.py`：受限 AST 算术工具。
- `assets/theme.css`：统一字号、配色和响应式布局。
- `paper_agent/agent.py`：兼容 API 客户端、工具注册、受限工具调度循环、证据引用检查。
- `tests/`：数据与检索测试、模拟模型工具调用测试、Streamlit 页面交互测试。

RAG 流程：原文 → 按页解析 → 页内优先沿段落或句尾切分（每片最多 1000 字符，尽量重叠上一句，最多重叠 200 字符）→ 中英文术语扩展 → BM25 与字符 2–4 gram TF-IDF 双路召回 → RRF 排名融合 → MMR 多样性排序 → 原文证据与页码 → 大模型生成。也可单独使用 BM25 或 TF-IDF。旧论文的检索片段会从已保存的逐页文字自动重建，历史对话和报告保留当时的证据摘录。
这是实际的关键词与稀疏向量混合 RAG，不是稠密 embedding 语义检索。无需下载 embedding 模型，中文和英文都可检索；跨语言或同义词能力有限，建议用原文关键词。对比时每篇论文独立召回，避免单篇占满结果。

会话历史持久保存，模型请求最多携带同一论文范围内的最近八条消息。长期记忆保存用户偏好和显式保存的笔记，按当前论文范围筛选并做简单关键词排序，最多读取八条。

工具列表：
- `search_papers`：仅检索用户选中的论文，可限制到一篇。
- `read_page`：读取选中论文的原文页以检查上下文。
- `recall_memory`：读取相关笔记和偏好。
- `paper_outline`：规则识别论文目录，限定在当前论文范围内；需要 read_page 核对。
- `calculate`：AST 白名单算术运算，不使用 eval；支持相对提升、均值等计算。

每次请求先执行记忆召回与逐篇检索，再由模型自主决定进一步工具调用。最多四轮，每轮最多八次；所有调用记录在回答展开栏。不执行论文中的指令，不提供任意代码执行工具。保存记忆由用户显式点击操作完成。

## 数据和边界

数据在 `data/library.sqlite3`，按项目路径定位，不受启动工作目录影响。可设置 `PAPER_AGENT_DATA` 更改数据目录。停止服务后复制 data 文件夹即可备份。
导入 PDF 后会在本地同时保存原件和提取文字。点击回答或证据中的页码链接可查看对应原页。升级前导入的 PDF 可以重新上传同一份文件补回原件，沿用原有论文 ID 和引用。删除论文会一并删除原件、提取文字、片段和关联笔记。历史对话和报告保留运行时的证据摘录。
本地模式不发送论文到外部。启用云模型后，检索片段、近期对话和选中范围内的记忆会发送至用户配置的接口。

当前版本限制：
- 不支持扫描件 OCR、图片理解、复杂公式或表格结构识别；空白页提示但不猜测内容。
- TXT/Markdown 按每 4500 字符划为虚拟页，PDF 保留原 PDF 页序号。
- 不提供联网找论文、自动 DOI 核验或真实论文的预置知识库。
- 索引按片段文本内容建立 LRU 进程缓存（最多四组），修改资料后自动使用新索引。仍适合小型个人文献库；大规模库应引入持久向量索引。
- 引用检查会标出未知编号和在对应引文里找不到的数值。云端模式还会发起一次独立的模型复核，标出结论与引文之间的疑点。科研使用前仍应核对原文。
- 单个文件最多 30 MB，PDF 最多 600 页。服务仅绑定本机，当前不含多人登录与权限隔离。

## 验证

```powershell
python -m unittest discover -s tests -v
```

测试不需要 API Key；工具调用采用模拟模型，因此不能代替用户服务商的实际接口验证。模型设置页提供连接与工具调用测试。

实现参考：[Streamlit 聊天组件](https://docs.streamlit.io/develop/api-reference/chat/st.chat_input)、[scikit-learn 余弦相似度](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.pairwise.cosine_similarity.html)。


## 本次升级：研究工作流

新增三个页面：
1. 证据检索：选择检索算法、结果数、术语扩展和多样性排序；显示各路分数、收藏原文片段、导出 JSON。
2. 精读工作台：快速精读、方法拆解、复现清单、自测问答四个任务模板；目录预览、引用核对、Markdown 导出与笔记保存。模板驱动真实 Agent 检索与工具循环；本地模式仅返回证据，不伪装生成内容。
3. 阅读计划：待读 / 精读中 / 已读、优先级、研究标签、关联论文待办、完成状态、清单导出和实验数值计算器。

记忆中心现在支持编辑已有笔记。模型设置新增检索偏好，当前浏览器会话中保存，作用于问答、对比与精读。数据库迁移只新增表，不覆盖既有论文、会话和记忆。

字体层级：主标题 32px、分区标题 25px / 21px、正文和输入框 16px、标签 15px、辅助文字 14px、侧栏导航 18px。桌面侧栏 308px；窄窗口下表单纵向排列、统计卡片分两列。颜色使用深青绿与浅灰绿，普通内容继续随 Streamlit 明暗主题成对变化。

DeepSeek 的工具调用回合会保留接口要求的 reasoning_content 字段用于协议衔接，不在界面展示或写入记忆。参考：[DeepSeek Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode/)。未使用用户密钥进行云端验证。

验证：14 项自动测试，覆盖旧功能、新混合检索与缓存、作用域限制、计划持久化、受限计算、工具协议及九页面交互；另在浏览器检查了总览与证据检索页的实际配色和窄屏布局。


## 分析过程面板与精简界面

问答、对比和精读现在会实时显示执行状态，完成后可展开“查看分析过程”回看时间线：任务准备、记忆召回、证据检索、模型请求轮次、工具结果与引用编号检查。每条记录来自实际执行事件；失败和待核对步骤单独标记。过程记录随聊天保存，兼容旧版工具日志。

面板展示实际执行摘要，`reasoning_content` 仅保留在单次请求的协议上下文中。云端模式的面板会分别显示引用和数值检查、模型结论复核的状态。本地模式会展示检索证据和对应页码。
